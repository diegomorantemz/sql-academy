# Proyecto: SQL Academy - Simulador de Base de Datos

Este proyecto es un simulador educativo de SQL, desarrollado como parte de un curso de 18 semanas para aprender flujos de trabajo colaborativos con Git y GitHub.

## Tecnologías

- HTML5, CSS3, JavaScript
- SQLite (sql.js)
- Chart.js
- Font Awesome
