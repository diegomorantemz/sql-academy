Comparativa de Gestores SQL vs NoSQL

Característica SQL (Relacionales) NoSQL (No Relacionales)
Modelo de datos Tablas con filas y columnas Documentos, Clave-Valor, Columnas, Grafos
Esquema Fijo (requiere definición previa) Flexible (schema-less)
Escalabilidad Vertical (más recursos en un servidor) Horizontal (distribución en múltiples servidores)
ACID Soporte completo Variable: algunos motores ofrecen transacciones; otros priorizan disponibilidad
Lenguaje SQL (Structured Query Language) APIs específicas (JSON, REST, etc.)
Mejor para Datos estructurados, transacciones complejas Grandes volúmenes, datos no estructurados, tiempo real
Ejemplos PostgreSQL, MySQL, SQL Server, Oracle MongoDB, Firebase, Redis, Cassandra, Neo4j

Sintaxis rápida

Usa una consola simplificada de MongoDB. No se ejecuta JavaScript arbitrario.

db.estudiantes.find({ edad: { $gt: 18 } }) db.estudiantes.insertOne({ nombre: "Ana" }) db.estudiantes.updateMany({}, { $inc: { edad: 1 } }) db.estudiantes.aggregate([{ $group: { _id: "$carrera", total: { $sum: 1 } } }])

Operadores: $gt, $gte, $lt, $in, $and, $or, $set, $inc, $push.
